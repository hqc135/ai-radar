## 本周概览

过去一周的高优先级信息显示，行业重心已从“模型跑分”转向“可验证的 Agent 工程化”。三条主线清晰：其一，Eval 成为基础设施——LLM-as-Judge 的偏差审计（Google Cloud）、评分器蜕变测试 SANE、过程感知基准 TauIndianBankBench 等表明，仅看最终答案会掩盖 6.5%-12% 的流程失败，评测正从结果分转向过程与证据级；其二，Agent 训练闭环加速——ThinkingBox 用数据库执行结果直接作 RL 奖励、Navalia 与 DataPraxis 合成可验证长程任务、AtomSD/SPEM 沉淀程序性记忆，显示“可验证奖励+技能复用”是提升 Agent 可靠性的主路径；其三，检索与上下文被重新定位为瓶颈，LangChain 与 EBG 论文均指出检索召回而非阅读能力才是 RAG 短板。模型侧，Kimi K3.1 Pro 逼近前沿且承诺开源权重，Mercury 3 以扩散并行生成切入低延迟；Google Antigravity 与 Vercel 分别给出跨模型验证、临时最小权限的 Agent 生产实践。同时，多智能体“降幻觉”假设遭临床研究证伪，医疗分诊出现“降级风险”谄媚失败，安全与权限治理需前置。

- 评测重心从最终答案转向过程级、证据级与权限级验证，仅看结果会系统性高估 Agent 成功率
