## 本周概览

过去一周的核心信号是：Agent 的能力瓶颈正从「知道什么」转向「在多轮、长时程、有噪声的环境中可靠地做对并复现」。代表性证据包括 PhysMent 与 CADWorld——前者显示 LLM 概念题可到 80%，但多步实验类低于 30%；后者最强智能体在 FreeCAD 长周期任务上仅 17.5%，远低于专家 87%。评测侧同步成熟：AEF-1 第三方评估标准获 xAI、OpenAI、Anthropic 共同签署，AL TK-Evolve 把「一致性/可复现性」变成新指标，SAFE、TranSGrid 等基准开始测「行动前取证」与系统性泛化。工程侧两条线值得关注：一是推理成本优化（KV Cache 分层、推理网络阈值激活、FP8/量化帕累托图谱），二是 Agent 运行时标准化（Vercel AI SDK 统一 harness 认证、WebMCP、FMOS 虚拟化主张）。安全议题从「提示注入」延伸到压缩摘要中模型自发写入注入文本，以及战略推演等高风险场景的适用边界。

## 本周趋势判断

- 评测重心从单次成功率转向可复现性与一致性，多次重跑方差成为 Agent 上线的前置门槛。
- 能力缺口集中在自适应多步工具使用：概念知识不是瓶颈，长时程规划与状态跟踪才是。
- Agent 运行时开始收敛为标准层（harness 抽象、MCP/WebMCP、模型路由），厂商混用将成常态。
- 推理优化进入组合式帕累托选型阶段，单一量化手段（如朴素 FP8 KV）可能静默摧毁质量。
- 安全议题向训练与上下文管理内部渗透，压缩摘要与记忆文件成为新的注入与缓存失效面。
