## 今日必看

### 1. [Finding the Move Is Not Winning the Game: XiangqiBench for Closed-Loop Evaluation of LLM Agents](https://arxiv.org/abs/2610.02425)

XiangqiBench 是一个可执行的闭环评测基准，用中国象棋战术残局考察 LLM Agent 能否将计划执行到被验证的结果。实验用 119 个必胜残局、12 个前沿模型、8568 条多轮轨迹，揭示三类高估：走出参考首步（26.1%）却仅 13.9% 取胜的转化差距；pass@3 达 38.7% 而 pass^3 仅 5.9% 的一致性差距；以及模拟中 32.3% 非法着法、49.3% 对手应变不符的模拟差距。结论：找到着法不等于赢棋，Agent 评测应打分闭环结果并报告可靠性。

- 来源：arXiv cs.CL | 2026-10-05 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：LLM Agent、Eval、Reasoning、Benchmark、Closed-Loop
- 为什么看：arXiv 官方来源可信度高；提出闭环 Agent 评测新范式，直击静态评测与真实执行能力的差距，与用户关注的 Agent、Eval、Reasoning 高度契合，量化证据充分，值得精读并纳入评测方法参考。
- 建议动作：deep_read

### 2. [DeReAct: Decomposed Reasoning and Acting for Reliable AI Agents](https://arxiv.org/abs/2610.02351)

DeReAct 提出模块化 Agent 架构，将动作授权与完成判定外置为两个门控策略：Critic 在执行前校验提议动作，Context Manager 重建有环境证据支撑的状态并认证任务完成。在 GAIA 与 SWE-bench Verified 上，该方法对较弱模型提升最大：Qwen3-Coder-480B 提升 6.5-7.0 分，Claude Sonnet 4.5 提升 4.2-5.2 分，模型越强增益越小；Opus 4.5 上与 ReAct 持平但轨迹更有证据支撑。

- 来源：arXiv cs.AI | 2026-10-05 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：Agent、Reasoning、ReAct、SWE-bench、GAIA、Eval
- 为什么看：来自 arXiv 原始论文，聚焦 Agent 推理与执行解耦这一高偏好方向，GAIA/SWE-bench 双基准定量验证，结论区分了模型强弱与门控有效性的边界条件，对 Agent 可靠性设计有直接参考价值。
- 建议动作：精读并纳入 Agent 架构参考，关注门控机制与评测复现

### 3. [When Terminal-Agent Training Stalls: Demystifying Data Generation and Verification Challenge](https://arxiv.org/abs/2610.02405)

该论文指出，用Claude Opus等前沿模型作元智能体生成终端任务与验证器进行RL训练虽常见，但可运行Docker镜像与测试套件并不能保证端到端流程可靠。作者诊断出基准无效、测试框架脆弱、奖励错位三类失败，通过重设计提示与扩展上下文使基线可解率提升5.6倍，但9B模型在Opus生成任务上20步内即饱和于81.3% pass@2；加入困难任务后降至20.6%，表明可解性区间与模型强相关。

### 4. [CUEing User Simulators: Calibrated User Embeddings for Multi-Turn Benchmarking](https://arxiv.org/abs/2610.02460)

该论文提出CUE（校准用户嵌入）框架，针对多轮交互式Agent评测中用户模拟器缺乏结果校准的问题，通过编码真实会话并采样连续表征，再解码为角色指令来引导LLM模拟用户，无需训练。在τ²-Bench上，CUEd模拟器减少模拟器归因错误，更真实复现真实用户的Agent失败模式与成功率，且不牺牲用户保真度，还能跨任务与不同模拟器LLM泛化。

### 5. [APDMem: Agent-Controlled Progressive Disclosure for Query-Adaptive Long-Term Memory](https://arxiv.org/abs/2610.02472)

提出 APDMem，一种面向个性化 LLM 助手的分层长期记忆架构，将对话历史组织为主题摘要、个性化关键事实、轮次级证据笔记和原始消息四层。推理时由控制器按需渐进披露，简单查询提前终止，复杂查询深入细粒度证据，形成成本与保真度的自适应权衡。在 LongMemEval 上仅访问约 8% 对话即可实现强长期记忆推理表现。
