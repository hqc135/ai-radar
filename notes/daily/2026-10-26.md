## 今日必看

### 1. [The Schema Coherence Inventory: Measuring Whether an Assigned Belief Organizes a Language Model's Cognition](https://arxiv.org/abs/2610.31683)

该论文提出模式一致性量表（SCI），用96道强制选择题、基于长度归一化对数似然打分，检验赋予语言模型的信念是否真正组织其行为，而非仅是情绪反应。在五个模型（1.7B-14B）的107个条件下验证，信念适配器在各模型上均呈现目标特异性（+17.7分）。论文还发现，六个已发表的病人模拟器均未能比一句核心信念陈述更好地携带其设定信念。作者公开了题目、评分代码和简版量表。

- 来源：arXiv cs.CL | 2026-10-26 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：Eval、Reasoning、LLM评测、人格化模型、心理测量、arXiv
- 为什么看：来自 arXiv 正式论文，具备完整验证流程，可用于评测模型的人格与信念一致性（覆盖 Eval 和 Reasoning）。它提出一种不依赖生成的似然打分评测范式，具备可复用价值；作者公开代码和数据，但尚属细分方向，不属于主流 Agent、RAG 应用。
- 建议动作：read

### 2. [Permission to Retry: A Study of Authorization and Recovery in AI Agent Workflows](https://arxiv.org/abs/2610.31916)

该论文研究工具型 AI Agent 的执行时可靠性，把恢复决策与模型行为分离，提出检查点状态、派发许可、外部效果证据、对账许可四类独立义务，并在 LangGraph 与 Temporal 上对 336 条历史做一致性实验；结果显示保留账本对账策略全部通过，而缓存重试、重试前复核、稳定键重试分别仅通过 30/36/31 条。

- 来源：arXiv cs.AI | 2026-10-26 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：Agent、工具调用、可靠性、授权与恢复、LangGraph、Temporal、Eval
- 为什么看：arXiv 原始论文，来源可信度高；主题正对 Agent 执行可靠性与恢复语义，属用户偏好方向，且给出可复现的对照实验与量化结论，对构建生产级 Agent 工作流有直接参考价值，但偏系统与形式化，非范式级突破，故重要性定为 4。
- 建议动作：read

### 3. [An Agentic Approach with Evidence-Grounded Verification for Multimodal Emotion Reasoning in Conversation](https://arxiv.org/abs/2610.31685)

该论文提出一种基于冻结模型的可溯源多模态情感推理智能体框架：视觉、声学、词汇感知智能体将带证据引用的观察发布到共享黑板，整合智能体结合检索到的多模态示例输出情感描述与标签，并由 MLLM 评审请求修订。另有证据核验阶段用确定性检查加蕴含判断定位错误来源，按责任组件生成定向提示补丁，经留出集验证后生效，无需更新权重。在 MER2025 上对 2B 至 38B 四个模型均带来 0.6-2.2 分 F-score 提升。

- 来源：arXiv cs.CL | 2026-10-26 12:00 | 重要性 4/5 | 可信度 4/5
- 标签：Agent、多模态、Reasoning、Eval、RAG
- 为什么看：arXiv 一手论文，可信度高；将 Agent 编排、证据核验与提示空间自适应结合，涉及错误归因与 Eval 机制，与用户对 Agent/Reasoning/Eval 的偏好高度契合；方法可迁移至其他多智能体系统，实验覆盖 2B-38B 多模型并有一致提升。虽属情感推理细分任务，但框架通用性使其值得细读。
- 建议动作：read

### 4. [SPECMEM: Accelerating Agentic Tool Calling via Live Memory Management](https://arxiv.org/abs/2610.31840)

SpecMem 提出面向工具调用型 Agent 的实时记忆管理机制：把已验证的工具调用在线写回按用户划分的有界存储，用 LRU 淘汰实现跨会话草稿缓存，并用副作用校验限制不可逆调用。在多用户多会话场景下，这比冻结存储显著提升投机解码接受率，平均多 27%，最高约 1.74 倍加速，但代价是存储维护复杂度上升。

- 来源：arXiv cs.CL | 2026-10-26 12:00 | 重要性 4/5 | 可信度 4/5

### 1. [Phronix: The Capability-Centric Learning Paradigm for Agents](https://arxiv.org/abs/2610.31789)

Phronix 提出以能力为中心的学习范式，让 Agent 的 harness 从自身执行中获取、验证并精炼可复用能力。其采用预测-验证-纠正循环：MCP 工具提出方案，执行结果验证，观察结果反向更新能力库；遇到失败任务不放弃而是深入研究。实验显示，已学能力首次解决重复任务成功率 93-95%；每任务自动沉淀 7.6-30.8 个能力；热启动每任务仅耗 0.38-0.40M tokens，比基线省 3-4 倍；SWE-bench 上两个廉价模型解决率从 29%/27% 提升至 91%/87%。

- 来源：arXiv cs.AI | 2026-10-26 12:00 | 重要性 4/5 | 可信度 4/5
- 标签：Agent、能力学习、MCP、SWE-bench、可靠性、Token 效率

### 2. [PaperFormalizer: Author-in-the-Loop Autoformalization of Research Papers in Lean](https://arxiv.org/abs/2610.31810)

PaperFormalizer 是一个基于 Lean 的 Agent 流水线，可把论文 LaTeX 源码转成依赖图，逐条校验陈述的忠实性与歧义，并在 Mathlib 上形式化证明。它采用作者参与（author-in-the-loop）机制：当陈述有多种读法或需要修复时，暂停并向作者提议，由作者决定，不擅自改动论文主张。该工具运行在 Claude Code 或 Codex 中，输出带注释修订版、变更报告及与陈述链接的 Lean 代码。

- 来源：arXiv cs.AI | 2026-10-26 12:00 | 重要性 4/5 | 可信度 4/5
- 标签：Autoformalization、Lean、Agent、Coding Agent、形式化验证、论文形式化
- 为什么看：arXiv 官方来源可信度高；结合 Agent 与 Lean 形式化，契合用户对 Agent、Reasoning 和 Coding 的偏好，且有开源实现与在线平台，工程可复现性强。但属数学形式化细分领域，短期产业影响有限，故重要性为 4 而非 5。
