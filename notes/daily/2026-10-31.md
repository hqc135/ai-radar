### 2. [What Does an Ontology Catch? Curated, LLM-Generated and Data-Derived Ontologies as Checkers of LLM Agents over Knowledge Graphs](https://arxiv.org/abs/2610.37809)

该论文将本体论检查器本身作为研究对象，系统比较人工整理、LLM 生成与数据推导三类本体，在公开知识图谱和近十亿三元组的私有图上检验其对 LLM Agent 问答的校验效果。作者指出，在 UniProt 上，人工本体误报正确答案的次数多于数据推导和 LLM 推导本体；面对真实 Agent 回答，它的精确率仅略高于随机标记。研究还讨论了不同来源本体在捕获错误与误报之间的权衡。

- 来源：arXiv cs.AI | 2026-10-31 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：Agent、Eval、知识图谱、本体论、LLM检查器、论文

### 3. [Measuring Where Intent Gets Lost in Agentic Smart Contract Synthesis](https://arxiv.org/abs/2610.37830)

该 arXiv 论文研究 AI Agent 生成智能合约时，意图在何处丢失。作者采用基于执行的评估方法：将同一组交易分别重放到 AI 生成的合约与原始合约，并统计结果一致率；同时用植入错误的样本检验 AI 评委和标准分析工具，发现它们会漏掉明显错误。论文进而提出 elicitation-first 架构：在写代码前先用少量问题向客户澄清需求，并用独立编写的可执行答案键做交叉验证，效果显著优于事后审查或修补。

- 来源：arXiv cs.AI | 2026-10-31 12:00 | 重要性 4/5 | 可信度 5/5
- 标签：Agent、Eval、代码生成、智能合约、需求澄清
- 为什么看：该论文来自 arXiv 正式渠道，实验体系完整，并已公开工具、600 个任务和结果，可信度高。其核心结论对 Agent 生成代码时的意图对齐与评测设计有直接借鉴价值，尤其适用于 Coding 与 Eval 场景；它提出的“先澄清需求、再生成代码”思路也可迁移到一般 Agent 任务，因此值得精读。
