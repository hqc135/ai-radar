### 1. [@ai-sdk/perplexity@5.0.0](https://github.com/vercel/ai/releases/tag/%40ai-sdk%2Fperplexity%405.0.0)

Vercel AI SDK 发布 @ai-sdk/perplexity 5.0.0，属破坏性更新：语言生成从 Sonar Chat Completions API 迁移至 Perplexity Agent API，模型 ID 与 provider 选项替换为 Agent API 的预设、模型与工具，请求响应元数据、流事件、用量成本数据均变化，且不再支持 Sonar PDF 输入及图像视频结果。附带修复流式文本恢复、原生工具轨迹保留、URL 引用标注等。
