### 1. [RAGCompass: Generalizable Retriever Routing via Reranking](https://arxiv.org/abs/2611.05596)

本文提出 RAGCompass，一种基于重排序的检索器路由方法。不同于依赖查询特征和固定检索器池的现有路由器，它直接读取各检索器返回的段落集合，通过对比式微调重排序器并辅以小型比较头，实现对陌生检索器和新语料的泛化路由。实验显示答案 F1 相比最佳固定检索器提升约 28%，优于融合基线和仅查询路由器，且在未见语料、检索器和阅读器下保持大部分收益。

- 来源：arXiv cs.CL | 2026-11-05 13:00 | 重要性 4/5 | 可信度 5/5
- 标签：RAG、检索路由、重排序、Eval、泛化

### 2. [Learning When Human Decisions Matter: Executor-Relative Consultation Value for LLM Agents](https://arxiv.org/abs/2611.05814)

该论文提出人类决策能力分配问题：在咨询次数与预算有限时，LLM Agent 应就哪些决策征询人类意见。作者提出 Consultation Value Distillation（CVD），用蒙特卡洛执行器 rollout 离线估计“执行器相关的咨询价值”，再蒸馏为轻量预测器供部署时分配，无需在线 rollout。在五个批式与三个顺序设定、两个前沿执行器上，CVD 优于直接提示与 Value of Information，且在监督更少时仍稳健。
